# MSFMIMD
## Microsoft Foundry for Medical Imaging &amp; Multimodal Data Professional Certificate
### Professional Certificate - 5 course series

Healthcare AI is transforming radiology, clinical informatics, and care coordination; the professionals who can evaluate, manage, and govern these systems are in high demand.

This program develops the practical AI skills healthcare administration professionals need to work confidently with medical imaging data, configure AI models, and uphold responsible data practices in governed clinical environments using Microsoft Foundry. 

In this professional certificate, you will learn to evaluate multimodal AI workflows connecting radiology images, clinical notes, and patient data; apply machine learning and computer vision models to imaging prediction tasks; extract clinical text using NLP; design healthcare data pipelines; assess CT and MRI imaging datasets for AI readiness; and implement data governance and privacy controls aligned with HIPAA requirements.

This program is non-programming and scenario-based, with no coding experience required. All projects are completed using guided scenario materials and AI-graded activities, ensuring every learner can produce professional, portfolio-ready artifacts regardless of live platform access.
